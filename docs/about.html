DTO-Bioflow

The DTO-Bioflow project enables the integration of biodiversity monitoring data into the Digital Twin Ocean. The importance of this project is demonstrated by several policy-relevant Demonstrator Use Cases (DUC). In order to facilitate the implementation of the DUCs, R scripts are provided to guide developers in the DTO.

  • In case you have a request for new guidelines or questions, use the GitHub Issues section.
    https://github.com/DTO-BioFlow/EDITO_data_R/issues.
  • In case you want to contribute, you are welcome to push your code to GitHub.
    https://github.com/DTO-BioFlow/EDITO_data_R.

This scripts in this repository are made available in EDITO as a tutorial.
